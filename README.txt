== Description ==

TheOct is an intentionally empty WordPress classic starter theme. The frontend renders no HTML, styles, or scripts until you choose to build it.

== Installation ==

1. Upload the theme ZIP in Appearance > Themes > Add New > Upload Theme, or copy the repository files to wp-content/themes/theoct/.
2. Activate TheOct.
3. The public-facing frontend will intentionally show a blank page. Add templates later to build the site.

== Description ==

TheOct is a clean and responsive classic WordPress theme for blogs, journals, news, and personal sites. It uses system fonts, no external dependencies, and accessible navigation.

== Features ==

* Responsive layouts and mobile menu.
* Custom site logo and primary/footer menus.
* Featured images and post excerpts.
* Optional widget sidebar.
* Blog, archive, search, page, single post, and 404 templates.
* Threaded comments and accessible search.
* Block editor color palette and editor styling.
* Translation-ready text domain: theoct.
* Right-to-left stylesheet.

== Installation ==

1. Place the theme files into wp-content/themes/theoct/ on your site, or upload a ZIP containing the theoct folder from Appearance > Themes > Add New > Upload Theme.
2. Activate TheOct under Appearance > Themes.
3. Go to Appearance > Menus to create/assign Primary and Footer menus, or configure menus in your WordPress admin's navigation settings.
4. Optionally add widgets to the Sidebar from Appearance > Widgets.
5. Set your site title, tagline, logo, and homepage content as desired.

== Frequently Asked Questions ==

= Is a page builder required? =

No. TheOct works with WordPress's core editor.

= How do I show the sidebar? =

Add widgets to the Sidebar widget area. It disappears automatically when empty.

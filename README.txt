== Description ==

TheOct is a blank-front-end classic starter theme. When activated, it automatically registers seven custom post types and nine taxonomies in the WordPress dashboard. The public frontend renders no HTML, styles, or scripts. Use the separate TheOct Fields v1.4.0 plugin for detailed custom field groups.

== Installation ==

1. Upload the theme ZIP in Appearance > Themes > Add New > Upload Theme, or copy the repository files to wp-content/themes/theoct/.
2. Activate TheOct.
3. Reload the WordPress dashboard: Services, Projects, Case Studies, Industries, Teams, Pricing, and FAQs are now available.
4. For detailed field groups, activate the separate TheOct Fields v1.4.0 plugin. In Dashboard, click Preview TheOct Fields Setup, review the import preview, and choose Apply Import.
5. The public-facing frontend will intentionally show a blank page. Add templates later to build the site.
